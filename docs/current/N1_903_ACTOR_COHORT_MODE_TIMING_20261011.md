# BSC N1 — RMB / Shift 成员模式复查时序的原生证据（2026-10-11）

**对象**：用户提供的原始 WH3 9.0.3 标记 EXE，SHA256 `518c4f292f275142df13b96b9db704a3db7b4870b2c519df83d850596ecc822a`；地址均为 RVA。**只读静态研究，不修改游戏，不等于 V3 动态分支证明。**

## 这次真正检查到什么

1. `0x03081EB4` 公共成员更新函数，在 `0x0308201F–0x03082090` 使用可变全局值 `0x03D0727C` 和常量 `1000.0` 计算正浮点分组除数。EXE 初始全局值为 `100`，`0x00587B64` 对正数加 `0.5` 并取整，因此**原始映像默认除数为 10**。运行时全局值是否保持 100，V3 没记录，不能保证。
2. 读取 `[member+0x58]+0x440` 指向的控制对象 `+0x98`，以及成员 `+0x60` 的编号类整数，分别执行无符号 `div r8d`。只有 `(counter % bucket_count) == (member_ordinal % bucket_count)` 才调用 `0x030716CC` 重新判断成员 `+0x318` 模式。如果返回的新模式与当前值不同，才通过 `0x03078B1C` 处理模式切换。若余数不同，跳到 `0x03082090`。
3. 此处**仅限制“模式重算”的一段**：`0x03082090` 之后的其他成员处理继续执行，例如 `0x03082165 → 0x03065584`。不能说士兵每十轮才能移动一次，也不能把 `+0x318` 直接定义为最终转向角或目标路点序号。
4. 群组目标 A 的已解析收包分支 `0x03073224` 会调用 `0x0315EC98` 处理姿态，在 `0x030732A4` **独立于上述余数门槛**调用**同一个** `0x03078B1C`，再进入 `0x03056ED4` 更新空间关联。这能让某些成员在接收阶段立即重新选择模式。但 A 的 `0x030D5490` 在旧 V3 中原 Hook 零命中，**不能称之为 V3 必经路径，也不能断言普通 RMB 永远走 A、Shift 永远走 B**。
5. 群组目标 B 的前分类处理 `0x03263C00/0x03263C0A` 写的是 `member+0xB10` bit7，**不是** `member+0x318`。仅凭这两处代码，不能说 B 已经同步切换全体成员模式；B 的下级路线对象目前也没有和主兵模最终运动积分器完成闭环。

## 适用范围：不是只影响 19 类

对原始构造器锚定的 **38 张成员虚表**，`+0x18` 入口共有 9 种：10 张直接指向公共入口 `0x03081EB4`，9 张指向 `0x02F854AC` 的直接跳转，剩下 **19 张**通过各自的更新方法内部 E8 静态调用 `0x03081EB4`。这 7 个 E8 已逐指令验证。**38/38 存在静态可达链**不意味着 38 类每次 Tick 都实际走到这里，调用可以被类型内条件阻断。

## 与原来的 RMB / Shift 模型如何对接

```
普通 RMB REPLACE: 新 MOVE(+0xA0=NULL) → 原生 MOVE 任务状态机
Shift MOVE→MOVE: 条件性续接共享状态 → 同一任务状态机
   ├─ 条件 A：0x26 成员目标包 → 0x03073224 → 即时调用 0x03078B1C（成员各自处理）
   └─ 条件 B：0x03263AB0 → 成员+0xB10 bit7 → 下级路线记录（实际动力学消费未闭环）
成员类型自有 +0x18 更新 → 全部静态能进入 0x03081EB4
   ├─ 只有轮到本成员余数组：0x030716CC → 可能 0x03078B1C → 更新+0x318
   └─ 其他逐成员更新仍可继续，**不存在已证实的全兵牌同帧切换屏障**
```

### 可证伪性与风险

- 这条机制解释**不同成员何时再次检查动作／运动模式可以不同**，并不证明新物理路径会因此延后相同的帧数。
- 初始 10 个桶只是**映像默认值**；“连续 0–59 编号”只是离线反例的输入，不是 V3 的成员编号实录。
- 假设控制计数逐次加 1，10 桶可造成至多 9 次控制计数推进间的复查相位差，但 V3 的计数推进节拍未记录；不能把它换算成实际秒数，更不能单独解释多秒持续的挤压。
- 普通 RMB 和 Shift 共享公共成员代码，所以**全球强制每 Tick 重算模式**不是一个有根据的 Shift 专用修复，可能影响正常 RMB 的性能或行动。
- 还需逆向：当 B 的路线段控制器被更换时，哪个实际成员主运动消费者读到新路线、是否同步更新 `+0x318`，以及旧 V3 所在群组 A/B 的动态路径。不能用静态分析倒推历史 V3 未记录的分支命中。
