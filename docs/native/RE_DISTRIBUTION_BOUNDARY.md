# Reverse-Engineering Distribution Boundary

This repository documents recovered semantics, RVAs, field relations, short guard signatures and reproducible relocation procedures. It does **not** redistribute `Warhammer3.exe`, CA DLLs, IDA/Ghidra databases containing the game binary, or large disassembly dumps.

The goal is to preserve engineering knowledge needed to relocate known roles after a CA update without redistributing proprietary game binaries.
