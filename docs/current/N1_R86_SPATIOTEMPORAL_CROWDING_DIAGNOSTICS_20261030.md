# BSC R86 — 同一兵牌的同时刻群体空间运动诊断（2026-10-30）

**主题是 Shift 连续 MOVE 折返时同兵牌士兵相互穿插/挤压的“群体情况”，而不是寻找名为挤压的原生动作。** 当前没有 gameplay 修复、游戏进程 Hook 或实机成员运动记录；玩家已经确认的缺陷不再要求重复证明。

## 1. 与当前游戏 EXE 直接相连的原生字段链

当前用户 EXE：232531920 bytes，SHA256 `9bd58c63bd7fc5c9909b3d3d9b6b7a6ae4eac784369bf91a9e53c3e9f42be496`，ImageBase `0x140000000`，下文地址均为 RVA。**本地原始文件完整核验**：51/51 原始指令字节 + LLVM 指令起点、4/4 E8、4/4 Jcc、5/5 PE unwind 函数范围；47/47 Python unittest 含原始 EXE；公共环境 46 PASS /1 SKIP。

- `0x0311E5DC`：在通常提交路径将成员目标记录复制到 `member+0x1E0` 和其 reference `+0x1F0`。**局部目标不是未经处理的世界坐标**。
- `0x03121F54`：读取目标记录+0x10 的引用；若空直接复制 xyz，若非空 `0x03121F68 E8→0x02F3D668` 根据参考 frame 转成世界 XYZ。不同引用可让同一局部 XYZ 得到不同世界坐标。
- `0x03059BC8` steering：`0x0305A05B` 条件分支可以**跳过**世界目标方向段；只有允许路径中的 `0x0305A06D E8→0x03121F54` 后，才用世界目标与本成员位置 `+0x88/+0x8C/+0x90` 计算方向，另读 `+0x1C0` 等速度输入。
- `0x03146FF0` 成员积分器：`0x031471B5/B8`、`0x031471C1/C4` 是受状态约束的控制流；允许分支 `0x0314720B/23/3B` 将 pending +0x13C/+0x140/+0x144 累计到物理 xyz，随后更新速度 +0xE0/+0xE8。
- `0x03086F04` 成员 Tick 在一条受条件保护的路径 `0x03087349 E8→0x03059BC8`，然后 `0x03087351` 调后处理。不能宣称每个 Shift 帧每名士兵都执行这些分支。

这些原始字节**不证明**某个 Shift 后继 MOVE 与这些成员同时命中或造成错误的实例级世界目标。

## 2. 首次独立对照空间路径相交与“同时刻相遇”

完整 `BSC_R86_SPATIOTEMPORAL_CROWDING_DIAGNOSTICS_20261030.zip` 中实现 `r86_kinematics.py` 与离线 CSV 工具 `r86_trace_cli.py`。每条轨迹由稳定 member identity、同一时间轴的世界 XZ 位置构成。

对任意两名成员，在共同时间区间的每段相对位置 `r(s)=r0+s*v`，解析 `s*=clip[-(r0·v)/(v·v),0,1]` 求**同一时刻最小间距**；另外独立计算两条几何线段的交点，以及两者穿过交点各自的时间。计算自选示范距离阈值下的接近持续时间。上述连续时间距离**只在样本点间按线性插值的离线模型内精确**，不是实际 WH3 的样本间曲线证明。

| 合成例（阈值仅用于模拟） | 同一时刻最小距离 | 证伪的草率推断 |
|---|---:|---|
| 两轨迹几何相交，但分别先后经过交点，时间差 0.5 | 2.0000 | **路径相交不必然出现挤压** |
| 两条路径同一时刻经过交点 | 0.0000 | 时间与空间交会应被区分 |
| 两条平行路线始终相隔 0.7，不相交 | 0.7000 | **路径不相交也可能持续距离太近** |
| 固定3×3槽位，单次180°直线插值 | 0.0000 | *特定插值假设*可产生中心拥挤，不是 CA 已证算法 |
| 固定3×3槽位，两次90°分段直线插值 | 2.1213 | 原生渐进折返不能用单次直线180°代替 |
| 固定3×3槽位，连续刚性180°旋转（200段近似） | 约2.9999 | **固定槽位仍能保持成员距离** |
| 相同目标、成员转向相位超前/滞后±0.18 | 约1.4687 | 仅成员转向进度差即可缩小距离；非 CA 参数 |

上述全部是**合成几何数学单位**，不是 WH3 的身体/碰撞盒半径；用户的原生缺陷依旧存在，但没有被这个模型归因。

理想刚性弯道横向半宽 H 与中心半径 R 对应内外侧局部线速度比例 `1-H/R`、`1+H/R`。R≤H 时所有士兵持续前进与保持完全刚性可能无法兼得，但没有证明 CA 的曲率限制就是这个值。

## 3. 实际修复逻辑的因果分叉

**若**以后能够在可信、安全的来源下获得同一 UnitRoot / 同一 queued MOVE 任务路段 / 同一时间轴 / 稳定成员身份下的世界 XYZ 和分支激活信息：

1. 将各人的局部 goal 与 reference frame 先解析成世界目标，不要直接用 `member+0x1E0` 当世界坐标。
2. 检查世界目标集是否已经发生错配。如果**目标本身**矛盾，优先研究目标生成、route/slot 分配和转向曲率。
3. 如果目标合理但**实际同时刻相互间距下降**，优先研究成员相位差、邻兵反应和运动积分，而不是立即全局改目标槽位或速度。
4. 只有空间路径交点但通过时间不同、间距没有缩小的情形，是负对照，不应称作碰撞。
5. 还未建立允许安全 live Hook 的 SEH/对象生存期/并发观测合同。本轮不使用 Derpy 已占用的 Tick 注入点，也不请求玩家重复实机测试。
