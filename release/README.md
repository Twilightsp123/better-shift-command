# Release Artifacts

The checked-in binary under `v1.0.0/` is the historical v1.0.0 Workshop pack.

v1.0.1 changed the Steam distribution model to a self-contained Windows x64 pack that embeds the Native Bridge and MinHook payloads. The authoritative v1.0.1 pack is built on the validated Windows v142-family toolchain using:

`tools/release_v1.0.1/BUILD_RELEASE_V1.0.1.ps1`

Do not mistake the archived v1.0.0 pack for the current release.
