# BSC 第22轮 / R56 — 后继 MOVE 朝向查表生成器与阵型投影连续性

日期：2026-10-20。Windows x64 `Warhammer3.exe` SHA256：`9bd58c63bd7fc5c9909b3d3d9b6b7a6ae4eac784369bf91a9e53c3e9f42be496`。全部地址为 **RVA**，不是 ASLR 后的进程地址。目标仍是让 CA 原生 Shift 连续 MOVE 折返更流畅，不使用 Lua 替代 Shift、不直接更改寻路或避障。

## 本轮真正新增的机器码发现

R54/R55 只证明 `0x03102B28` 从 `0x03E8F360` 查出二维 float 值，它在磁盘 EXE 中全为零；所以此前**没有**证明 lookup 是单位方向向量。本轮反向找到真正初始化入口：

```
0x00186474   E8 -> 0x006042E8           直接初始化调用者
0x00604304   LEA RSI,[0x03E8F360]      查表写入地址
0x0060430D   MOVSX EAX,DI               把16位角度解释为signed整数
0x00604314   CVTDQ2PS XMM6,XMM6
0x00604317   MULSS XMM6,[0x039228A0]   角度比例 0.0000958738019107841 (2π/65536)
0x00604322   E8 -> 0x01120900          双分量角度数学例程
0x00604335   SHUFPS XMM1,XMM0,1
0x00604339   MOVSS [RSI+RAX*8],XMM0    写第1个分量
0x00604341   MOVSS [RSI+RAX*8+4],XMM1  写第2个分量
0x00604366   CMP EDI,0x10000           遍历65536个角度编码
```

其角度数学例程在零角度附近的 **机器码快路径** 包含 `0x01120934` 读取常数 `1.0f`、`0x0112093C SUBPS`、`0x0112093F UNPCKLPS`、`0x01120942 RET`。对于角度 0，输入0，得到 packed (0,1)，与 `(sin θ, cos θ)` 分量一致。其他角度通过 SIMD/数学分支，因此将表称作**原生角度二维三角分量查表**有强静态依据，但本轮**没有执行原生数学例程或验证全部 65536 项的浮点误差、符号方向和正交性**。

再次验证 `0x03102BE6 LEA RCX,[0x03E8F360]` 使用的就是**同一张表**；`0x03102BF7`、`0x03102BFC` 读取 `heading*8` 的两项，后续通过 `0x03102C2D..0x03102C5A` 对世界坐标实施 `0.5f*(A-B)*V(heading)` 修正。R55 已独立证明 A 来源于 Group 布局策略并体现空间跨度，**不是已定型的转弯半径**。

## 路段交接时刻的原生顺序

R53/R54 已证两类后继 MOVE（保存 `slot+0x98` 朝向 vs 当前 Group 推导朝向）均调用 `0x030179B0`。在此函数所核对的 rich route 分支：

1. `0x030179C7` 从 R8W 保存朝向；`0x03017A69` 再将其转交描述符构造器 `0x030F1B3C`。
2. `0x03017A47` 取当前 Group+0xB30 策略，计算当前排布跨度 A；`0x03017A79` 将 A 与朝向写入新描述符。
3. `0x03017AA3` 调 `0x0301E890` 对旧路线关联状态做条件性清理；`0x03017AB6` 构造/引用新路线；`0x03017ABB` 将结果发布到 `UnitRoot+0x270`。

**注意：** 当前局部函数中未发现显式对旧/新 heading 的数值插值；但 `0x0300D948 → 0x03126A58 → 0x03102B28`、后续节点/成员任务可能执行连续性控制，不能据此说 CA 实际直接瞬变、更不能说一定发生挤压。`0x0301E890` 的具体引用管理作用也不能被解释成所有旧运动状态立刻消失。

## 方向变化与跨度变化是两个独立的潜在误差源

设 `D=A-B`，坐标参考输入 `C` 固定，则原生二维位置修正的**数学形式**是：

`P = C - 0.5 * D * V(θ)`

任意相邻路段的投影偏移差为：

`ΔP = -0.5 * (D_next*V(θ_next) - D_prev*V(θ_prev))`

如果额外假设方向查表是理想单位三角向量、且 `D_prev=D_next=D`，则**数学上**有：

`|ΔP| = |D| * |sin((θ_next−θ_prev)/2)|`

例如纯合成参数 D=16：转向 30° 时理论约 4.14，90° 时约 11.31，180° 时约 16 距离单位；**这不是游戏内兵模移动距离或目标突变证据**。

反之若 θ 完全不变但 D 变化，距离差量级为 `|D_next-D_prev|/2`。因此将 `A` 当作转弯半径直接调大/调小，可能改变编队投影基准而非改善曲率。更有价值的是把 `heading` 和 `extent` 在**同一次有效路段交接**记录出来，定位变化究竟来自预存/实时朝向切换还是布局策略改变。
